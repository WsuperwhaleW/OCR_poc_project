            HYBRID PROMPTS
            แต่ละเอกสารถามอะไรพร้อมกันบ้าง
            แต่ละกล่องคือหนึ่งคำถามที่ส่งให้โมเดล ฟิลด์ในกล่องเดียวกันจะถูกถามพร้อมกัน
            
      
            
        
            ก้อน prompt
            
        
            ประเภทที่ถามฟิลด์ Required และข้อความเหมือนกันทุกอย่างอยู่ก้อนเดียวกัน ลากประเภทไปก้อนอื่นเพื่อใช้แบบเดียวกัน ลากไปช่อง “แยกออกมาแก้” เพื่อแก้เฉพาะประเภทนั้น หรือกดที่ก้อนเพื่อแก้ข้อความของทั้งก้อน เลือกฟิลด์และ Required ได้ที่ Doc types ของ User
