For several documents use the Queue tab, which decides how many run at once and starts on its own Run. A random document, a random model to read it, a random model to extract from it, a random Detail and shape — run end to end, as many times as you ask for. The document is not random: each round goes to whichever case the run log has read fewest times, so every fixture is covered eventually rather than whenever it is lucky. The number beside each case is how many reads it already had. This is the only thing here that tests the whole path: the benchmarks feed pass 2 a ground-truth transcript on purpose, so nothing else automatically exercises decoding, resizing, the pass-1 profile, the case match and extraction together.

Every round is a real run and appends its own row to the run log — a random test whose results were kept out of it would be measuring a path nobody else uses. The settings are left where the last round put them rather than restored, so a combination that broke something is still selected when it stops.
